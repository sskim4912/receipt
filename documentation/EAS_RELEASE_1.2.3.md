# Aurora EAS 1.2.3

직원 PC에서 1.2.2 실행 시 확인된 EDGE-DRIVER 오류에 대응해 Selenium과 Selenium Manager를 4.27.1에서 4.52.0으로 업데이트합니다. 이전 Windows 관리 바이너리는 msedgedriver.azureedge.net을 사용하며, 새 바이너리는 현재 Microsoft 공식 배포 주소 msedgedriver.microsoft.com을 사용합니다. 다른 주소로 중계하거나 회사 보안 설정을 변경하지 않습니다.

새 관리 도구로 Windows x64 Edge 142용 공식 드라이버를 실제로 다운로드하여 정상 종료와 EXE 형식을 확인했습니다. 이는 테스트 버전이며 직원 PC의 Edge 버전을 가정하지 않습니다. 프로그램은 설치된 Edge에 맞춰 드라이버를 자동 선택합니다. 직원 PC의 인터넷·회사 정책에 의한 별도 제한이 있으면 추가 확인이 필요합니다.

기존 전용 Edge 프로필과 거래 대조, 사용자 확인, 자동 저장 금지를 유지합니다. 기존 EAS 작업을 확인하고 창과 보조 프로그램을 종료한 뒤 포탈에서 새 ZIP을 내려받아 모두 압축 풀기 후 EXE로 업데이트합니다.

동일한 테스트 환경과 Edge 142 조건에서 이전 Selenium Manager는 이전 주소 요청에 실패(code 65), 새 Manager는 현재 공식 주소를 통해 실제 드라이버 다운로드에 성공(code 0)했습니다. 이 비교는 직원 PC 자체에서 수집한 네트워크 진단을 대신하지는 않습니다.

직원이 제공한 Edge 156.0.4314.58(64비트) 조건에서도 새 Manager가 동일한 156.0.4314.58 Windows x64 드라이버를 공식 주소에서 실제 다운로드하는 데 성공했습니다. 직원 PC의 회사 로그인·Edge 실행 자체에 대한 종단 간 검증은 미실시입니다.

검증: Python 91개 중 90개 통과·로컬 원본 미배치 검사 1개 건너뜀, 다운로드 검증 4개 통과. frozen 자체 검사와 Wine에서 1.2.3 등록 확인 창을 통과했고, NSIS 무결성과 설치 페이로드 1,415개 파일의 일치를 확인했습니다. PC·갤럭시·아이폰 크기 Chromium 화면의 실제 ZIP 다운로드·대체 다운로드 검증 3개를 통과했습니다. 이 환경의 Wine에는 32비트 지원 DLL이 없어 Windows용 Manager 자체 실행은 확인하지 못했으며, 공식 wheel의 Manager로 Linux에서 Windows 대상 드라이버 다운로드를 검증했습니다.
