# Aurora EAS 1.2.2

직원 PC의 실행 실패와 상세 화면 대기 실패를 구분하도록 보완했습니다.

- 원본 접속 모듈이 삼킨 Edge 생성 오류를 안전한 코드로 표시합니다. 드라이버 준비, 버전 불일치, 전용 프로필 사용 중, 실행 권한 거부, Edge 미설치 등을 구분하며 원문 오류의 경로·인증 URL은 표시하지 않습니다.
- 거래 날짜를 누른 원래 창과 그 클릭으로 새로 생긴 창만 확인합니다. 이전에 열려 있던 다른 상세 창은 선택하지 않으며 상세 창이 여러 개면 중단합니다.
- 상세 표의 직접 텍스트 제목과 기존 중첩 제목을 모두 인식합니다. 상세 항목·입력란의 누락과 읽기 전용 상태를 구분하며 최대 45초 기다립니다.
- 거래 대조, 사용자 확인, 3개 항목만 입력, 자동 저장 금지를 유지합니다.
- 등록 확인과 중단 메시지에 앱 버전을 표시합니다. 실행 중인 보조 프로그램을 감지하면 설치를 중단해 부분 업데이트를 방지합니다.

업데이트: 작성 중인 내용을 확인하고 기존 EAS Edge와 보조 프로그램을 종료한 뒤 포탈에서 새 ZIP을 다운로드하여 모두 압축 풀기 후 EXE를 실행합니다. 로그인 프로필은 유지합니다.

직원 PC의 실제 실패 원인은 제공된 이전 오류 창만으로 확정할 수 없습니다. 회사 SSO와 해당 직원의 Windows·Edge 환경에서 최종 연결 확인이 필요합니다. 회사 인증 및 최종 저장은 사용자가 직접 수행합니다.

검증: Python 테스트 91개 중 90개 통과, 로컬 원본 미배치 검사 1개 건너뜀(별도 비공개 원본 SHA-256 검증 통과). Windows 바이너리는 Wine에서 frozen 자체 검사·버전 확인 창·실제 Windows mutex/인증 named pipe 검증을 통과했습니다. NSIS 무결성과 설치 페이로드 1,397개 파일의 해시 일치를 확인했습니다. Windows 실기기·회사 SSO 종단 간 검증은 미실시입니다.
