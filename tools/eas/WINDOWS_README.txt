Aurora 영수증 → EAS PC 직접 연결 (Windows 사용자마다 최초 1회)

1. ZIP 전체를 새 폴더에 압축 해제하고 INSTALL.cmd를 실행합니다.
2. 기존에 정상 작동한 eas_card_automation.py와 Python 환경을 자동으로 찾습니다.
   PyCharm 프로젝트, 검증 폴더, 기존 설치 폴더에서 승인된 해시의 코드만 찾습니다.
   자동으로 찾지 못한 경우에만 원본을 한 번 선택합니다.
   원본을 변경하지 않고 LocalAppData의 새 설치 폴더로 복사합니다.
   회사 기준 코드는 공개 ZIP에 포함하지 않습니다. 최초 설치 시 사내 담당자에게 받으세요.
3. Python 3.11 이상과 tkinter가 필요합니다. 정상 작동한 기존 환경을 우선 사용합니다.
   Selenium 환경을 찾지 못하면 기존 프로젝트를 변경하지 않고 전용 가상환경을 자동 준비합니다.
   새 환경에는 Selenium 4.27.1을 설치하며, 회사 네트워크 정책에 따라 준비가 제한될 수 있습니다.
4. 이 Windows 사용자에게 연결을 자동 등록하고 설정 완료 창을 표시합니다. 관리자 권한은 필요하지 않습니다.
5. 관리자 웹 화면에서 새로고침 → 영수증 상세 → 전자전표 연결 → EAS 보조 프로그램으로 연결.
   브라우저에서 외부 프로그램 열기를 허용합니다.
6. PC 요청 확인 → 저장된 SSO 세션 재사용(최초·만료 시 직접 로그인) → 자동 공지 닫기 → 거래 확인 → 3개 입력 확인.
   실사용자·인원수·목적만 입력하고 저장은 사용자가 직접 합니다.
   상세의 실제 거래 정보와 입력란이 준비될 때까지 기다린 후 입력합니다.
   입력이 중단되면 중단 단계와 이유를 별도 안내 창으로 표시하고 EAS 화면을 유지합니다.

PC 재부팅, 브라우저 재접속, 다음 날에도 등록은 유지됩니다. 매번 다운로드/설치하지 않습니다.
다른 영수증을 연결할 때는 이전 연결로 열린 Edge 창을 먼저 닫아주세요.
같은 PC라도 다른 Windows 계정이면 최초 등록이 한 번 필요합니다.
회사에서 PC 연결 등록을 제한하면 IT 담당자에게 설치를 요청하세요.
모바일에서는 Windows EAS 보조 프로그램을 실행하지 않습니다.

등록은 HKCU/Software/Classes/aurora-eas에만 저장합니다. 서버·포트·시작프로그램은 없습니다.
영수증 전달 내용은 PC 프로그램의 메모리에서 처리하고 JSON 파일로 저장하지 않습니다.
앱 연결 URL에는 이름·사용내역이 들어갑니다. URL·프로세스 실행 인수를 공유하지 마세요.
URL 발신 사이트를 운영체제에서 인증할 수 없으므로 연결 요청 내용을 PC에서 먼저 확인합니다.
요청은 5분 내에만 접수하며 거래 대조와 입력 전 확인을 생략하지 않습니다.
SSO ID/Password/PIN/OTP는 수집하거나 자동입력하지 않습니다.
Edge가 관리하는 로그인 상태는 %LOCALAPPDATA%/AuroraEAS/EdgeProfile에 유지됩니다.
재설치·재부팅 후 같은 Windows 사용자에서는 같은 전용 프로필을 사용합니다.
최초 로그인, 세션 만료, 회사 추가 인증 시에는 직접 로그인해야 합니다.
이 폴더는 공유하지 마세요. 공용 Windows 계정에서는 세션도 공유됩니다.
초기화는 전용 Edge에서 로그아웃하거나 모든 EAS Edge 창을 닫고 EdgeProfile 폴더를 삭제하세요.
기존 설치 사용자는 새 ZIP을 풀고 INSTALL.cmd를 다시 실행해야 적용됩니다.
기존 영수증 DB, O/X, 처리상태, OCR, 저장, 비용구분, 계정과목은 변경하지 않습니다.

등록 해제: 설치 완료 창에 안내된 LocalAppData/AuroraEAS/v1-.../UNINSTALL.cmd를 실행합니다.
파일은 삭제하지 않으며, 재설치하면 새 폴더에 등록합니다.
INSTALL.cmd가 Python을 못 찾으면 기존 PyCharm 터미널에서:
  .\.venv\Scripts\python.exe "압축 해제한 폴더\install_windows.py"

이 버전의 INSTALL.cmd는 ASCII와 Windows CRLF 줄바꿈으로 배포합니다.
웹사이트가 최초 설치와 브라우저의 앱 열기 허용을 대신할 수는 없습니다.

기존 파일 선택 방식도 보존됩니다. 설치가 제한되면 웹 도움말의 파일 다운로드를 사용하세요.
